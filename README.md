# Jaktlag 1.1 Premium, korrigerad areal och statistik

## Korrigeringar
- Markinnehav anges i hektar, inte procent.
- Summan av alla hektar betraktas som jaktlagets totala areal och motsvarar 100 procent.
- Varje medlems markandel beräknas som `medlemmens hektar / total hektar * 100`.
- Statistiken uppdateras direkt med sparade hektarvärden.
- Erhållna djur räknas som djurets vuxenekvivalent gånger mottagarens andel. Exempel: 50 procent kalv/kid delad 40/60 ger 0,20 respektive 0,30 vuxenekvivalenta djur.
- Statistik per viltslag använder samma beräkning efter filtrering.

Ladda upp samtliga filer till roten av ditt GitHub-repository och ersätt de tidigare filerna.
